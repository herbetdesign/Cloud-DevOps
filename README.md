# Solução Serverless com Azure Functions

Projeto prático desenvolvido como parte do bootcamp da DIO, com foco na criação de uma arquitetura serverless utilizando Azure Functions, Logic Apps e Service Bus.

## Descrição
A solução implementa funções serverless acionadas por requisições HTTP, que processam dados e publicam mensagens em um serviço de mensageria. Uma Logic App é responsável por orquestrar o fluxo e realizar a persistência dos dados, demonstrando uma arquitetura desacoplada, escalável e orientada a eventos.

## Arquitetura
- Azure Functions (HTTP Trigger e Service Bus Trigger)
- Azure Logic Apps
- Azure Service Bus
- Banco de Dados (conceitual)

## Objetivo
Demonstrar o uso de computação serverless, integração entre serviços Azure e automação de fluxos em ambientes cloud-native.

## Conceitos abordados
- Serverless
- Event-driven architecture
- Mensageria
- Automação de processos
- Integração de serviços em nuvem
